# Floade Work Map（實驗）

獨立 Electron 視窗，用來共用會持續改變的思考脈絡。Floade 面板的「框選翻譯」右邊有 Work Map 入口，安裝包包含此實驗功能；視窗與 AI API 都獨立運行，沒有傳送給 GPT 的功能。重複點入口會切回已開啟的視窗。

預設資料目錄在 Windows 的 `%APPDATA%\Floade\work-map`，以下 `data/` 都指這個資料目錄。開發版與安裝版共用同一份地圖，更新安裝不會覆蓋它。首次從舊獨立版啟動時，會原樣複製專案 `experiments/shared-map/data` 的加密地圖、AI 紀錄與解密所需的 profile 金鑰設定，原檔保留作備份；已有新目錄地圖時不覆蓋。自訂 `--map-profile` 不執行遷移。

在 need 專案根目錄執行 `npm ci`，然後 `npm run experiment:map`。Windows 也可以雙擊本資料夾的 `開啟共用地圖.vbs`，或執行 `Open Map.ps1`。

畫布必須維持嚴格的上下樹狀圖：非空時只有一個根，每個其他節點只有一個上層，不能循環、跨分支連線或產生第二個上層。同一深度對齊，整個子樹自動避開其他子樹，父節點底部以直角分支接到子節點頂部。新增、修改上層、調整大小和 AI 修改後都會重新排列。舊圖首次開啟會轉為樹狀圖，原圖與轉換差異保留在加密修改紀錄；原本分離的分支接到根下，文字、外觀與隱私設定保留。

左上角小地圖顯示全畫布的物件輪廓、連線與藍色視野框。點擊可跳轉到對應位置，拖曳視野框可平移；小地圖聚焦時也可用方向鍵移動。縮放、拖動物件、視窗大小與 AI 修改都會同步更新。它不顯示物件文字，且遵守畫面隱私設定；遮蔽整個物件時，小地圖也排除該物件與相關線。

空圖右鍵可新增根節點；已有地圖時，右鍵物件可新增其子節點，右鍵空白處則加在目前選取節點或根下。刪除中間節點會把其子節點接到原上層；仍有子節點的根不可刪除。中鍵移動畫布、滾輪縮放、F 看全圖。直接左右拖曳物件可調整同一上層的順序，藍色插入線顯示放置位置，整個子樹會一起重新排列；跨層拖放不會改上層。修改上層請使用上下連接點或面板的上層選單。點物件會在畫布內開啟可獨立拖動的編輯面板，允許同時開啟多個；面板與開啟位置會保存，但暫時顯示的隱私文字不會保存。物件、連線與補充面板都會依實際尺寸限制在畫布內，拖曳、平移、縮放、視窗大小或內容尺寸改變時重新限制；內容過高時在面板內捲動，標題與關閉鈕保持可操作。

物件旁以晶片與眼睛小圖示顯示目前 AI／畫面的實際可見狀態：綠色完整、黃色遮蔽文字、紅色隱藏物件；全域或暫時顯示覆蓋個別設定時以紫色邊框標示，hover 可看完整說明，直接點圖示會依「完整 → 遮蔽文字 → 隱藏物件 → 完整」循環切換此物件的個別設定並保存，不開啟面板；Enter／空白鍵也可操作。全域覆蓋保持不變，圖示仍顯示實際狀態，說明會標示個別設定及下一次切換。畫面隱藏後可從底部切到「全部顯示」，再點眼睛圖示恢復個別設定。畫面隱藏整個物件時也不顯示其圖示。物件面板可編輯想法、上層與隱私，並以「同層往左／往右」調整順序；展開「外觀」可改形狀、背景與文字色、大小、不透明度。補充文字改由節點旁以曲線連接的小圓球開啟，在文字泡泡內查看與編輯；有內容時圓球會填色，空白時顯示加號。游標停留圓球時會預覽補充文字，長文可在預覽內捲動；移開即收起，點擊仍可編輯。預覽遵守畫面隱私，不會改動或保存地圖。右鍵圓球可選「移除補充內容」並直接清空保存；文字遮蔽時不能移除。圓球是節點的附屬顯示，不是另一個樹節點，仍使用原本的 `note` 與隱私設定。選取物件右下角也可拖曳調整大小。沒有固定側欄或頂部標題／脈絡列。

## 把腦中的地圖輸入進來

輸入只統一「物件中的文字」與「物件之間的連線」。內容可以模糊、矛盾、不完整；畫布結構仍維持唯一根與單一上層；不要求填寫原因、起點、猜想、已驗證等固定分類或狀態。先放入一個念頭或選擇，之後依實際回饋繼續補寫與連接，不必先填滿一套分析欄位。

你可以直接說原話，由 AI 整理成物件與連線，也可以用這個文字約定指出你想怎麼放：

```text
〔A〕
先隨便下一個決定。
假設你在空無一物的地方，就隨便下一個決定，看看環境反饋。

〔B〕
看看環境反饋。

〔A — B〕
先下一個決定，再看看環境反饋。
```

這是 AI 整理文字的約定；目前沒有新增貼上匯入按鈕或文字解析器。A、B 是對話中的臨時稱呼，實際 id 由 AI 處理。使用既有面板也能直接填入同樣的文字。

| 位置 | 寫法 |
| --- | --- |
| 想法 `title` | 容易辨認的一句原話或忠實短句，允許留白 |
| 補充圓球 `note` | 自由補充原話、背景、例外、混雜的感受或暫時說不清楚的部分；可省略 |
| 關係 `label` | 用你自己的話描述這兩個物件怎麼連著；可留白，不需挑選關係類型 |

整理時保留「可能」「暫時」「但也許」等措辭及相互矛盾的內容。不自行補上因果、時間順序、驗證結論或未發生的回饋。沒有命名的父線只表示上下脈絡，不自動表示因果、執行順序或可信度。端點方向由父到子決定，位置由固定分層決定；文字仍能自由說明這個上下脈絡。單一物件可以容納你想一起看的多個念頭，不強制拆成最小命題。

原話太長時放進補充文字；過長的關係可用另一個自由文字物件承載完整描述再連接，不要為了欄位上限截斷重要內容。JSON Schema 與現有 API 都有長度限制；實際寫入以 API 驗證為準。

AI 的機器輸入草稿使用 [input.schema.json](input.schema.json)，完整示範見 [input.example.json](input.example.json)。這些檔案沒有要求語意分類。範例只是上面那段話的表示，沒有聲稱任何決定或回饋已經實際發生。

草稿須由 AI 轉成既有 [API](API.md) 的 `node.create/update`、`edge.update` 操作後寫入；它不是可直接傳給 `client.cjs apply` 的請求，也不會直接覆蓋整張圖。既有物件沿用 id、保留文字、外觀與隱私；草稿沒列出的物件不代表刪除。用 `parentId` 指定上層、`order` 指定同層順序，位置由程式統一計算。新節點的父線自動建立，須重新讀圖取得連線 id 再補關係文字。唯一根、唯一上層、無循環等限制由 API 檢查。上下分層只規範結構，不把內容自動解釋為因果。

寫入時重新取得 AI 可讀圖與 `revision`，依目前隱私可見範圍形成變更，附 actor、reason、requestId、expectedRevision，透過 `client.cjs apply` 套用。超過 100 個操作須重新分批規劃並逐批取得最新版本；409 時重新讀圖，不以舊版本盲目重試。

## 樹狀連線與隱私

滑鼠移到物件時，上下出現連接點（根只有下方接點）。從下方拖到另一節點，會將目標設為子節點；從上方拖到另一節點，則把目標設為自己的上層。這會替換原父線，不能把自己或子孫設為上層。所有連線固定使用上下直角分支，不提供曲線、控制點或自由路徑。

點線可編輯自由關係文字、粗細、顏色與實線／虛線。關係文字保留在面板與 AI 版本中，主畫布不在分支線上重複鋪字，讓樹狀分層清楚。父線不能單獨刪除，請修改子節點的上層。

AI 與畫面隱私各自控制，彼此不連動：

- 每個物件可設定完整、遮蔽文字或遮蔽整個物件。
- 全域 AI「全部開放」覆蓋個別 AI 限制；切回「依物件設定」會恢復限制。
- 全域畫面可依個別設定、全部顯示或遮蔽全部文字（整個物件的隱藏設定仍保留）；所有已開面板都會同步遮蔽。暫時顯示只影響該物件，關閉它的面板、按 Esc 或更改全域畫面模式會恢復遮蔽。
- AI 只能依 `data/ai-map.json` 取得目前允許的內容。遮蔽物件會連同相關線與父層引用被排除。畫面遮蔽也涵蓋所有面板的標題、文字與關聯；隱藏整個物件時，它和相關連線的面板也會關閉。

`data/map.private` 使用 Electron safeStorage 加密；`data/ai-map.json` 是允許 AI 讀取的明文輸出。這是應用程式與 AI 的讀取約定，不是阻止所有本機工具存取資料的安全邊界。私人資料、輸出和測試 profile 都被 Git 忽略；提交的 seed 只有通用示範內容。

舊的 `organization.json` 整理計畫只在舊圖轉換前讀取；樹狀模式請使用具版本與紀錄的 API 修改。

`npm run test:map` 驗證樹狀結構、固定分層、直角分支、遷移保留、API 原子拒絕及隱私。以 `electron experiments/shared-map/main.cjs --map-profile=<全新絕對測試目錄> --remote-debugging-port=9246` 啟動獨立測試視窗，attach 後以 Playwright CLI 執行 `run-code --filename=<tests/tree-ui-check.js 的絕對路徑>`，驗證新增子節點、改上層、同層排序、循環阻擋及重開保存。`tests/note-orbs-ui-check.js` 驗證補充圓球、編輯保存、位置對齊及兩組獨立隱私設定。`tests/note-hover-ui-check.js` 驗證 hover 預覽、長文捲動、移開收起、切換編輯／右鍵選單、文字安全顯示與隱私。`tests/visibility-reorder-ui-check.js` 驗證兩種可見性圖示、全域覆蓋及左右拖曳排序保存。`tests/visibility-toggle-ui-check.js` 驗證圖示直接循環切換、鍵盤操作、保存與重開、全域覆蓋、隱藏後恢復，以及已開面板同步。`tests/panel-bounds-ui-check.js` 驗證各類面板在小視窗、拖曳、平移縮放、展開內容、文字區域調整大小與舊越界位置恢復時仍能操作。可加 `--map-test-hidden` 在背景測試。`tests/ui-check.js` 與 `tests/connections-ui-check.js` 是舊自由畫布測試，不適用於樹狀操作。不要對使用者的私人 profile 執行測試。

3D 目前暫緩：先讓目的、選擇與驗證的關係清楚；日後可以用同一張圖的另一種視圖探索 3D，無須把第三維當成固定資料層級。

AI 可透過獨立的本機 [AI API](API.md) 讀取／建立／修改／刪除物件及線條，指定上層與同層順序，查詢每次 AI 修改前後的加密紀錄，並取得指定世界座標區域的 PNG。API 沿用 AI 隱私設定，禁止改隱私，具版本衝突檢查與請求重試去重。實際樹狀 API 測試可在獨立 profile 執行 `node experiments/shared-map/tests/tree-api-live-check.cjs <profile>`；原生重開後再加 `--restart` 驗證保存。

Codex plugin 的本機 MCP 與安裝方式見 [Floade Work Map plugin](../../plugins/floade-work-map/README.md)。
