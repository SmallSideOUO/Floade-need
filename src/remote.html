常用裝置

把家裡電腦的固定密碼儲存一次，之後一鍵連線。密碼由這部電腦的 Windows 加密保護。

連線／新增裝置

請使用家裡電腦的固定密碼；臨時密碼會失效。儲存裝置不會驗證密碼或更改對方電腦的權限。

完整存取家裡電腦

在家裡電腦設定一次：設定固定密碼、在「完整存取裝置」加入這部裝置的代碼，並安裝系統服務以操作管理員程式與登入畫面，再回到這裡儲存裝置。完整存取權限由接收端決定。

連線路徑

依每部裝置的成功率、穩定時間、FPS 與通道延遲紀錄計算最佳直連方式。連線成功後固定使用，短暫異常先等待恢復，持續失敗才重新評估。原有手動設定保留。

畫面與效能

畫面設定套用至新連線。實際 FPS 取決於兩端與網路。僅允許 P2P 直連；直連失敗時不會使用中繼。

相對滑鼠快捷鍵

在遠端桌面視窗按 Ctrl+Alt，即可切換相對滑鼠移動。點選下方欄位並按下想用的快捷鍵，再儲存設定，例如 Ctrl+Alt+M 或 F8。

套用至這部電腦的遠端視窗；使用快捷鍵前，先點一下遠端畫面。

完整存取裝置

允許的裝置通過密碼驗證後，可完整控制這部電腦；其他 ID 會被拒絕。裝置代碼是連線過濾，並非身分證明。變更套用至新連線。

Windows 管理員與登入畫面

將原生 LocalSystem 服務安裝至 Program Files，以支援管理員程式、UAC 與登入畫面。安裝時需要同意 Windows UAC 提示，遠端登入仍需密碼。
